# 已知边界与历史问题

- 原生窗口使用 Windows API，Linux 云环境无法完成真实桌面验收；跨平台测试只验证统计、日志、MCP 和合成事件。
- `codex-ipc` v11 属于内部桌面接口。Codex 更新后可能不兼容；此时回退日志，文字速度与本机全局覆盖可能受限。
- 额度和 Token 报告可能延迟，报告均速不等于瞬时模型性能。
- 当前交付为源码安装版；便携启动器原型尚无完整安装/更新/卸载流程，不提供安装包验收承诺。
- 历史本机版本首次设置登录伴随时，曾使用 `New-Item Run -Force`，可能影响其他软件的登录启动值。没有事前快照，无法确认或恢复原值。当前代码只修改/删除自己的 `CodexPulseCompanion` 值；不要通过猜测重建旧值或覆盖整个 Run 键。历史记录保留在上传资料中，本次未操作任何用户注册表。
